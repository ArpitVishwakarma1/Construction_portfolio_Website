# ARPIT Constructions — Website Source

A responsive, premium construction and civil engineering website inspired by the visual style of the uploaded reference HTML (dark background, gold accents, elegant typography, animated sections, portfolio filters, and WhatsApp contact).

## Files
- `index.html` — page content and SEO metadata
- `style.css` — styling, responsive layouts, animations
- `script.js` — mobile navigation, portfolio filters, reveal animations, WhatsApp enquiry form

## Run locally
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` directly, or use the Live Server extension for a local preview.

## IMPORTANT: personalize before publishing
This is a demo template. Replace:
- `ARPIT CONSTRUCTIONS` with your friend's actual business/engineer name
- `+91 98765 43210` and every `919876543210` in HTML/JS with the real phone/WhatsApp number
- `hello@ARPITbuild.in` with a real email address
- `Your City, India` with the actual service area
- Portfolio photos, project names and claims with actual work and accurate information

Do not publish invented reviews, ratings, years of experience, project counts, or client claims. This template intentionally avoids fake testimonials and specific performance claims.

## Images and fonts
The site uses Unsplash-hosted demo images and Google Fonts. Internet access is needed for these assets. Replace them with the business's own project photos for a stronger and more credible website.

## Enquiry form
The form prepares an enquiry and opens WhatsApp. It does not save submissions to a database. Change the demo WhatsApp number in `script.js` before going live.
